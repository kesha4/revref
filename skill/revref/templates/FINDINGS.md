# Реестр находок

Все находки всех ревью прогона. Пишет только оркестратор. Подробности — в отчётах по ссылке.

**Статусы:**

| Статус | Значение |
|---|---|
| открыто | Найдено, не проверено |
| подтверждено / с поправками | Прошло верификацию |
| ложное | Опровергнуто верификацией (остаётся в реестре, чтобы не появлялось снова) |
| нужна информация | Вопрос в `DECISIONS.md` |
| устарело | Код изменился после проверки, нужна повторная верификация |
| в работе | Задача выполняется |
| исправлено | Влито в ветку прогона |
| исправлено извне | Исправлено чужим коммитом |
| отложено | Ниже порога, бюджет или решение владельца |
| ждёт владельца | Связано с решением D-NNN класса B или C |
| заблокировано | Не удалось исправить; причина в задаче |
