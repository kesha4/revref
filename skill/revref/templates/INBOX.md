# Входящие ответы владельца

Сюда дописываются ответы владельца, данные вне сессии оркестратора: командой `/revref ask` из параллельной сессии или вручную. Только дописывается.

Оркестратор на ближайшей границе шага переносит ответы в `DECISIONS.md` с пометкой «ответ из INBOX <дата>» и удаляет перенесённые записи отсюда (PROTOCOLS.md §7).
