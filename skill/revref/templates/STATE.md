# Состояние прогона RevRef

Чекпоинт для продолжения в любой сессии. Пишет только оркестратор. Порядок возобновления — `PROTOCOLS.md §6`.

- Обновлено: ГГГГ-ММ-ДД ЧЧ:ММ
- Версия набора: X.Y.Z                <!-- из VERSION при init; меняется только при обновлении набора по PROTOCOLS.md §6 -->
- Тип чекпоинта: лёгкий | полный | прогон завершён | готово к слиянию | прогон влит в <ветка> <hash> | PR создан <ссылка>
- Ветка прогона: revref/ГГГГ-ММ-ДД
- Базовый коммит прогона: <hash> — откуда начался прогон
- HEAD перед записью чекпоинта: <hash>
- Режим: конвейер | очередь
- Текущая волна и шаг: W<n> — <ревью | верификация | план | исправления | ворота | веха>
- Приостановленный конвейер: — | W<n>/<шаг> (если во время прогона запущена очередь)
