# HYG — Гигиена кода

Префикс ID находок: HYG. Применяй вместе с `prompts/common-rules.md`.

Проведи ревью гигиены кода. Найди:
- мёртвый код: неиспользуемые функции, классы, экспорты, файлы, недостижимые ветки;
- неиспользуемые импорты, переменные, параметры;
- неиспользуемые зависимости в манифестах, а также ассеты, скрипты, переменные окружения и ключи конфигурации;
- закомментированные фрагменты кода, отладочный вывод (console.log, print, dump), временные хаки и заглушки;
- устаревшие TODO/FIXME/HACK: уже выполненные, потерявшие смысл или без понятного следующего шага;
- feature-флаги, которые навсегда включены или выключены;
- тривиальные обёртки, которые ничего не добавляют;
- вводящие в заблуждение имена: имя обещает одно, а код делает другое.

Прежде чем объявить код мёртвым, проверь неявное использование: рефлексию, вызов по строковому имени, роутинг и DI по соглашениям, шаблоны, конфиги, скрипты сборки, тесты, публичный API для внешних потребителей. Используй анализаторы экосистемы, если они доступны (например, knip, ts-prune, vulture, deadcode, staticcheck).

Раздели находки на две группы:
1) Можно удалить безопасно сейчас — с минимальным патчем для каждой находки.
2) Нужно решение — что именно неясно и как это проверить.
