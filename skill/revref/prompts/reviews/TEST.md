# TEST — Тесты

Префикс ID находок: TEST. Применяй вместе с `prompts/common-rules.md`.

Проведи ревью качества и покрытия тестов.

Если возможно, запусти тесты и инструмент покрытия и опирайся на реальные цифры: сколько тестов, сколько падает, сколько длится прогон, каково покрытие по модулям.

Покрытие:
- какие модули протестированы, где пробелы, какие критические пути (деньги, права доступа, данные, основные сценарии пользователя) не покрыты;
- баланс уровней: модульные, интеграционные, end-to-end;
- приоритет пробелов: критичность пути × частота изменений кода.

Качество самих тестов:
- проверяют поведение или детали реализации; переживут ли они честный рефакторинг;
- хрупкие и нестабильные (flaky) тесты: зависимость от времени, порядка запуска, сети, случайности, общего состояния;
- избыток моков, при котором тест проверяет моки, а не код;
- тесты без проверок или со слабыми проверками, бессмысленные тесты ради цифры покрытия;
- для ключевых тестов ответь: какой реалистичный баг этот тест не поймает;
- скорость прогона и запуск тестов в CI.

Предложи конкретные тесты для непокрытых участков: название, сценарий, входные данные, ожидаемый результат — в порядке приоритета. Для топ-5 приведи код теста в стиле проекта.
