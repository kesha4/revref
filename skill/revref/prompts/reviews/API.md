# API — Контракты API

Префикс ID находок: API. Применяй вместе с `prompts/common-rules.md`.

Проведи ревью контрактов API — внешних (HTTP, gRPC, GraphQL, CLI, SDK) и внутренних между крупными модулями или сервисами. Проверь:
- согласованность: именование, форматы дат и идентификаторов, пагинация, фильтрация, сортировка, единый формат ошибок с кодами и понятными сообщениями;
- семантику: методы и коды ответов, идемпотентность, поведение при повторе запроса;
- обратную совместимость: какие изменения уже сломали или сломают существующих клиентов; есть ли версионирование и политика вывода из эксплуатации;
- описание контракта: есть ли схема (OpenAPI, protobuf, JSON Schema), совпадает ли она с реальным поведением, валидируются ли по ней входящие и исходящие данные;
- избыточность и недостаточность: лишние поля, раскрывающие внутреннее устройство, или нехватка данных, из-за которой клиенту нужны лишние запросы;
- лимиты: размер запроса, частота, таймауты — заданы ли и задокументированы ли.

Для каждой находки укажи, каких клиентов она затрагивает, и способ исправления без поломки существующих интеграций.
