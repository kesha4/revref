# CMT — Комментарии в коде

Префикс ID находок: CMT. Применяй вместе с `prompts/common-rules.md`.

Проведи ревью комментариев в коде, включая docstrings и описания публичного API. Внешние документы не оценивай — для них есть отдельные ревью.

Найди:
- комментарии, противоречащие коду, — самые опасные, критичность повышена;
- устаревшие комментарии, описывающие прежнее поведение, и исторические записи в стиле «раньше было так, а теперь так» — история принадлежит системе контроля версий;
- избыточные комментарии, пересказывающие очевидный код;
- запутанные, противоречащие друг другу или сами себе пояснения;
- смешение языков и стилей комментирования в пределах проекта.

Обратная сторона — где комментария не хватает:
- неочевидное «почему»: причина выбора решения, обходной путь, ограничение внешней системы;
- магические константы, сложные алгоритмы и регулярные выражения;
- публичный API без описания контракта: параметры, возвращаемое значение, ошибки, побочные эффекты.

Предложи правки списком по файлам: удалить / переписать (с новым текстом) / добавить (с текстом). Для удаляемых комментариев укажи, не теряется ли полезное знание, и куда его перенести, если оно нужно.
