# I18N — Интернационализация

Префикс ID находок: I18N. Применяй вместе с `prompts/common-rules.md`.

Проведи ревью интернационализации и локализации. Проверь:
- захардкоженные строки интерфейса, сообщений об ошибках, писем и уведомлений вне системы переводов;
- склейку фраз из кусочков, которая ломается в других языках; плюрализацию (1 файл / 2 файла / 5 файлов);
- форматирование дат, времени, чисел и валют с учётом локали и часового пояса пользователя;
- полноту и актуальность переводов: отсутствующие, устаревшие и неиспользуемые ключи; поведение при отсутствии перевода;
- вёрстку: удлинение текста при переводе (до 30–40%), поддержку RTL, шрифты для нужных алфавитов;
- сортировку и поиск с учётом языка, регистра и диакритики;
- выбор и сохранение языка пользователем, язык по умолчанию.

Если проект одноязычный и мультиязычность не планируется, оцени в одной короткой секции только форматирование дат, чисел и валют и готовность к переводу в будущем.
