# DEC — Декомпозиция

Префикс ID находок: DEC. Применяй вместе с `prompts/common-rules.md`.

Проведи ревью декомпозиции кода. Найди:
- крупные файлы и модули со смешанными ответственностями (ориентир — больше 400–500 строк, с поправкой на язык и тип файла);
- перегруженные функции (ориентир — больше 50 строк), глубокую вложенность (больше 3 уровней), длинные цепочки if/else и switch;
- «божественные» классы и объекты, длинные списки параметров, boolean-флаги, переключающие поведение функции;
- смешение уровней абстракции в одной функции: бизнес-правила вперемешку с I/O, форматированием, запросами к БД.

Ориентиры — не правило. Большой, но связный файл (таблица констант, конфигурация, сгенерированный код) — не проблема. Не дроби ради дробления.

Для каждой находки:
- риск для поддерживаемости: что конкретно станет трудным;
- план разбиения в виде последовательности шагов, каждый из которых сохраняет поведение и проверяется отдельно (извлечь → перенести → заменить вызовы → удалить старое);
- если участок не покрыт тестами, первый шаг — характеризационные тесты, фиксирующие текущее поведение.
