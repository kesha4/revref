# DX — Сборка, CI/CD и опыт разработчика

Префикс ID находок: DX. Применяй вместе с `prompts/common-rules.md`.

Проведи ревью инфраструктуры разработки и доставки. Проверь:
- онбординг: можно ли развернуть проект с нуля по README одной-двумя командами; сколько неочевидных ручных шагов (попробуй пройти их, если возможно);
- воспроизводимость сборки: зафиксированы ли версии рантайма и инструментов, lock-файлы, контейнеризация; одинаково ли проект собирается локально и в CI;
- инструменты качества: линтер, форматтер, проверка типов, pre-commit-хуки; согласованы ли их настройки между собой и с CI;
- CI: что проверяется (тесты, линт, типы, сборка, audit), чего не хватает, сколько длится прогон, есть ли кэширование;
- конфигурацию и секреты для разных окружений: как задаются, где хранятся, есть ли шаблон (.env.example), проверяется ли конфигурация при старте;
- деплой: автоматизирован ли он, есть ли понятный процесс отката, миграции в процессе деплоя, разделение окружений;
- повседневные задачи: есть ли скрипты для типовых операций (запуск, тесты, сброс БД, генерация кода) и описаны ли они.

Ранжируй улучшения по экономии времени команды и снижению риска поломки при деплое.
