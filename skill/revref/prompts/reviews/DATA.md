# DATA — Данные, БД и миграции

Префикс ID находок: DATA. Применяй вместе с `prompts/common-rules.md`.

Проведи ревью работы с данными. Проверь:
- соответствие схемы предметной области: сущности, связи, нормализация, именование;
- ограничения целостности (NOT NULL, UNIQUE, FK, CHECK) там, где сейчас их обеспечивает только код приложения;
- индексы под реальные запросы: недостающие, избыточные, неиспользуемые;
- транзакционные границы и уровни изоляции: операции, которые должны быть атомарными, но не являются ими;
- миграции: обратимость, безопасность на непустой БД (блокировки, долгие ALTER, перестройка индексов), порядок деплоя «код ↔ схема», совместимость старой версии кода с новой схемой на время деплоя;
- хранение денег, дат и часовых поясов, перечислений, JSON-полей;
- жизненный цикл данных: soft delete, архивирование, удаление персональных данных, неограниченно растущие таблицы;
- бэкапы: есть ли они, проверялось ли восстановление, какой допустимый объём потери данных.

Для каждой находки укажи сценарий порчи, потери или рассогласования данных и безопасный план исправления, включая миграцию существующих данных.
