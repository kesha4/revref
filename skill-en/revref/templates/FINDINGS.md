# Findings register

All findings from all reviews of the run. Written only by the orchestrator. Details are in the linked reports.

**Statuses:**

| Status | Meaning |
|---|---|
| open | Found, not verified |
| confirmed / confirmed with corrections | Passed verification |
| false | Refuted by verification (stays in the register so it does not reappear) |
| needs information | A question in `DECISIONS.md` |
| stale | The code changed after verification; re-verification is needed |
| in progress | A task is being carried out |
| fixed | Merged into the run branch |
| fixed externally | Fixed by someone else's commit |
| deferred | Below the threshold, budget, or the owner's decision |
| waiting for owner | Tied to a class B or C decision D-NNN |
| blocked | Could not be fixed; the reason is in the task |
