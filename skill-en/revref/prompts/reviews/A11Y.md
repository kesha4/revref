# A11Y — Accessibility (a11y)

Finding ID prefix: A11Y. Use together with `prompts/common-rules.md`.

Review the accessibility of the interface against WCAG 2.2, level AA. If a browser is available, check the actual render, including with automated checks (axe, Lighthouse), but do not limit yourself to them.

Check:
- keyboard: is everything reachable without a mouse, is focus visible, is the tab order logical, is focus trapped inside modal dialogs and returned after closing, is there a "skip to content" link;
- semantics: headings follow the hierarchy, landmarks, lists, buttons are buttons and links are links; ARIA — exactly as much as needed, and without errors;
- forms: field labels, error messages are associated with fields and announced, required fields are marked by more than just color or an asterisk;
- images and icons: alt text on meaningful ones, decorative ones hidden, labels on icon buttons;
- color: contrast of text and UI elements, information is not conveyed by color alone;
- dynamics: are notifications and page changes announced (live regions), is prefers-reduced-motion respected, is there no autoplay or flashing;
- zoom: works with text enlarged to 200% and at 320 px width without loss of functionality.

For each issue: file and line, the violated WCAG criterion, who is affected (screen reader users, keyboard users, low-vision users, etc.), a concrete fix.
