# Техническое задание: Demo Shop

## 1. Пользователи

1.1. Регистрация по email и паролю. Email уникален.
1.2. Пароли хранятся только в виде стойкого хеша с солью.
1.3. Поиск пользователя по email.

## 2. Заказы

2.1. Заказ состоит из позиций: артикул, количество, цена за штуку на момент заказа.
2.2. Скидка 5% на позицию при количестве от 10 штук.
2.3. НДС 20% начисляется на сумму после скидок.
2.4. Итог заказа округляется до копеек по правилам бухгалтерии (банковское округление не используется — только математическое, половина вверх).
2.5. Пустой заказ оформить нельзя: пользователь получает понятную ошибку.

## 3. Оплата

3.1. Оплата через платёжный шлюз PayGate.
3.2. Повторная отправка платежа не должна приводить к двойному списанию.
3.3. Ключ доступа к шлюзу задаётся через переменную окружения `PAYGATE_API_KEY`.

## 4. Возвраты

4.1. Полный возврат оплаченного заказа по команде `refund <id заказа>`.

## 5. Отчёты

5.1. Отчёт по продажам: число заказов, выручка, средний чек.
5.2. Экспорт отчёта в CSV.
