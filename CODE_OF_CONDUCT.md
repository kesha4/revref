# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We as members, contributors and maintainers pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion or sexual identity and orientation.

## Expected behaviour

- Be respectful and constructive, especially when reviewing someone's code or idea.
- Assume good faith; critique the work, not the person.
- Give actionable feedback: what is wrong, why it matters, what would help.
- Respect privacy: no personal data, client data, secrets or private project details in public threads.
- Accept that maintainers may reject a contribution for scope, safety or maintenance-cost reasons.

## Unacceptable behaviour

- Harassment, insults, threats, discrimination or sexualised attention.
- Publishing someone's private information without permission.
- Deliberately derailing discussions, spam or repeated bad-faith arguments.
- Encouraging others to bypass security controls, provider terms or the law.

## Scope

This code applies in all project spaces: issues, pull requests, discussions, reviews, and any public or private communication made in the project's name.

## Enforcement

Report incidents to **kesha4elovek@gmail.com** with the subject `[conduct]`. Reports are reviewed by the maintainer on a best-effort basis. Possible actions include a private warning, removal of content, temporary or permanent ban from project spaces.
